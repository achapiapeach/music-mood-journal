# 노래로 남긴 마음 · 음악 감정 일기

YouTube Music 시청 기록(Google Takeout의 `watch-history.json`)을 분석해서 **언제, 무엇을, 얼마나 반복해서 들었는지** 보여주고, 그 노래를 듣던 날의 **마음**을 함께 기록하는 웹 앱입니다.

- 빌드 과정 없음 — `index.html` 한 파일로 동작합니다.
- 서버 없음 — 올린 파일은 어디로도 전송되지 않고 브라우저 안에서만 처리됩니다.
- 이 저장소에는 **어떤 사람의 시청 기록도 들어 있지 않습니다.** 처음 열면 비어 있고, 원하는 사람이 자기 기록을 올려서 씁니다.

**바로 쓰기 → https://achapiapeach.github.io/music-mood-journal/**

## 쓰는 법

1. [takeout.google.com](https://takeout.google.com) 에서 **모두 선택 해제** 후 **YouTube 및 YouTube Music**만 선택
2. **여러 형식** → `history` 항목을 **JSON**으로 변경 (기본값은 HTML이에요)
3. 내보내기를 누르고, 도착한 ZIP을 풀어 `Takeout/YouTube and YouTube Music/history/watch-history.json` 파일을 찾기
4. 사이트에서 **내 watch-history.json 올리기** → 파일 선택 (드래그 앤 드롭도 됩니다)

기록이 아직 없어도 **샘플로 둘러보기**를 누르면 가상의 기록으로 화면을 먼저 볼 수 있습니다.

## 화면

- **분석** — 전체 재생 수, 고유한 곡 수, 가장 많이 들은 시간대, 최다 아티스트 / 시간대별 청취 막대 차트 / 가장 많이 반복한 곡 TOP 15 / 자주 듣는 아티스트 TOP 10
- **감정 기록** — 날짜·곡·아티스트와 그때의 마음(행복, 설렘, 평온, 몽글몽글, 지침, 우울, 화남, 집중)을 여러 개 고르고 강도(1–5)와 한 줄 메모를 남깁니다. 타임라인에서 수정·삭제할 수 있어요.
- **모아보기** — 감정별로 묶어서, 그 마음이었을 때 주로 들은 노래와 남긴 메모를 봅니다.

## 데이터와 개인정보

- 업로드한 `watch-history.json`은 `FileReader`로 브라우저 안에서만 파싱되고, 네트워크로 나가지 않습니다.
- 분석 결과와 감정 기록은 그 브라우저의 `localStorage`에 저장됩니다. 기기를 바꾸거나 백업하려면 **내 기록 내보내기**로 JSON 파일을 받아 두고, 다른 기기에서 **기록 가져오기**로 불러오세요.
- 브라우저 저장 기록을 지우면 함께 사라집니다. 비공개(시크릿) 모드에서는 저장이 막힐 수 있어요.

## 참고

- YouTube 시청 기록에는 곡이 **시작된 시각**만 담겨 있습니다. 실제 재생 시간은 알 수 없어서, 반복 횟수와 시간대를 기준으로 분석합니다. 짧은 시간에 몰려 있는 기록은 플레이리스트·자동 재생일 수 있어요.
- 일반 YouTube 영상 기록은 음악 기록이 아니므로 제외합니다(숫자는 화면에 표시).
- 테마는 라이트/다크를 지원하고, 마지막 선택을 기억합니다.
