# 노래로 남긴 마음 · 음악 감정 일기

어디서 들었든 — YouTube Music, Spotify, Apple Music, 멜론, 지니, FLO, 벅스, 바이브 — 내가 반복해서 들은 노래와 그때의 마음을 한곳에 모으는 웹 앱입니다.

**바로 쓰기 → https://achapiapeach.github.io/music-mood-journal/**

- 빌드 없음 — `index.html` 한 파일로 동작 (HTML + CSS + JS, 외부 의존성 0)
- 서버 없음 — 올린 파일은 어디로도 전송되지 않고 브라우저 안에서만 처리
- 첫 화면에는 사이트 주인이 공개한 **YouTube Music 기록(음악만, 12,307회 · 2,925곡)** 이 초벌 감정 분류와 함께 실려 있습니다. 내 파일을 올리면 내 기록으로 바뀌고, `기본 기록 지우기`로 비울 수 있습니다.

## 무엇을 할 수 있나요

| 화면 | 하는 일 |
| --- | --- |
| **분석** | 플랫폼별 파일을 올려 시간대·플랫폼·자주 듣는 곡과 아티스트를 봅니다. 시간대별 감정 결(새벽·오전·오후·저녁)도 함께 나옵니다. |
| **기록** | 곡과 마음을 남깁니다. 감정 8개 위에 세부 감정 12개(신남·화남·슬픔·수면 계열)를 더 골라 쪼갤 수 있습니다. |
| **정리** | 시청 기록에서 곡별 초벌 감정을 자동으로 붙이고, 한 곡씩 들어 보며 고쳐서 `확인 완료`로 넘깁니다. |
| **모아보기** | 감정별로 그때 들은 곡과 메모를 모아 봅니다. |
| **추천** | 지금 마음과 목표(이어가기·끌어올리기·진정시키기)에 맞는 곡을 근거와 함께 고릅니다. |
| **데이터** | 내 기록을 JSON·CSV로 내보내고, 친구 기록을 합쳐 함께 보고, 백업합니다. |

## 지원하는 기록 파일

| 플랫폼 | 파일 | 비고 |
| --- | --- | --- |
| YouTube Music | Google Takeout `watch-history.json` | 일반 YouTube 영상은 자동으로 걸러냅니다 |
| Spotify | `StreamingHistory_music_*.json`, `Streaming_History_Audio_*.json`, `endsong_*.json` | 예전·새 형식 모두, 30초 미만 스킵과 팟캐스트는 제외 |
| Apple Music | `Apple Music Play Activity.csv`, `Apple Music - Play History Daily Tracks.csv`, `Library.xml` | `PLAY_END` 행만 사용, 보관함 XML은 재생 횟수·마지막 재생일 기준 |
| 멜론·지니·FLO·벅스·바이브 | CSV · TSV · TXT, 목록 붙여넣기 | `곡명 - 아티스트` 줄 단위, 날짜·횟수 붙여도 인식 |
| 그 외 (Last.fm 등) | CSV · TSV · TXT | 헤더를 보고 열을 자동으로 맞추고, 안 되면 직접 지정 |

- 파일은 **이름과 내용을 보고 자동으로 형식·플랫폼을 알아냅니다.** 여러 파일을 한 번에 올리면 합쳐서 분석합니다.
- CSV/TSV는 헤더로 곡명·아티스트·날짜·횟수 열을 찾습니다. 애매하면 **열 지정 화면**에서 직접 고를 수 있습니다.
- `samples/` 폴더에 플랫폼별 예시 파일이 있어 바로 시험해 볼 수 있습니다.

## 감정 기준

- **축**: 긍정도(불쾌 ↔ 쾌) × 에너지(이완 ↔ 각성) — 4사분면 Q1 활기 · Q2 긴장 · Q3 가라앉음 · Q4 잔잔함
- **감정 8개**: 행복 · 설렘 · 평온 · 몽글몽글 · 지침 · 우울 · 화남 · 집중
- **세부 감정 12개**
  - 신남: 텐션업 · 산뜻/기분좋음 · 리듬/그루브
  - 화남·강렬: 스트레스 해소 · 빡센 비트 · 짜증/분출
  - 슬픔: 이별/그리움 · 먹먹함/새벽 감성 · 우울/위로 필요
  - 수면·평온: 잘 때/평온 · 잔잔함/기도·휴식 · 나른함/몽환
- **시간대**: 새벽 00–05 · 오전 06–11 · 오후 12–17 · 저녁 18–23
- **확신도**: 확실해요 / 그런 편이에요 / 잘 모르겠어요 (통계·추천 가중치)

### 자동 초벌 분류

올린 곡마다 아티스트·곡명 키워드와 청취 시간대로 초벌 감정을 붙입니다.

- CCM·찬양 아티스트/곡명 → 잘 때 · 평온
- 센 비트 랩·하드트랙 → 강렬함 · 빡센 비트 (분노 키워드면 짜증 · 분출)
- 이별·눈물·후회 키워드, 사랑 발라드 → 슬픔 · 이별/그리움
- 랩·빠른 곡 → 신남 · 텐션업 / 댄스·팝 → 신남 · 리듬/그루브 / 그 외 대중음악 → 신남 · 산뜻
- 새벽(00–05)이 그 곡을 가장 많이 들은 시간대이고 2회 이상 들었으면 슬픔 · 먹먹함(새벽)으로 보정 (빠른 랩은 신남 유지)

오디오 분석이 아니라 **고칠 수 있는 초안**입니다. `정리` 화면에서 곡을 들으며 고치고 확인 완료로 넘기면 그 기록이 추천과 통계에 반영됩니다.

## 데이터와 개인정보

- 올린 파일은 서버로 보내지 않고 브라우저 안에서만 읽습니다. 감정 기록은 `localStorage`에 남습니다.
- `데이터` 탭의 **내보내기**는 날짜·시간대·곡·아티스트·감정·강도·확신도·맥락·플랫폼만 담습니다. 시청 시각 원본과 메모는 기본으로 빠집니다.
- 기본으로 실린 기록은 사이트 주인이 공개하기로 한 **음악 기록만**입니다(일반 YouTube 영상 80,831건은 포함하지 않음). 방문자가 자기 파일을 올리거나 `기본 기록 지우기`를 누르면 그 브라우저에서는 기본 기록이 사라집니다.
- 저장 공간이 부족하면 기록이 브라우저에 남지 않을 수 있으니, 오래 쓰려면 가끔 백업하세요.

## 구조

```
index.html          앱 전체 (화면 + 스타일 + 로직)
data/
  default-records.js  첫 화면에 실리는 기본 기록 (dataset + 초벌 분류 entries)
samples/            플랫폼별 예시 파일
README.md
```

기본 기록을 바꾸려면 `data/default-records.js`의 `window.__MMJ_SEED__`를 앱의 **전체 백업 내보내기** JSON 구조(`dataset`, `entries`)로 갈아 끼우면 됩니다.
